Accessibility fixture corpus

pipeline

public synthetic capture, sampling, observation and execution-accounting checks with matched controls

  • pipeline fixtures

delivery

the same defect delivered many different ways — server HTML, client-rendered, iframes, shadow DOM, web components

  • delivery fixtures

patterns

ARIA Authoring Practices component patterns as matched broken/correct pairs — dialogs, combobox, tabs, menus, tables and more

  • patterns fixtures

color-independent

colour used as the only carrier of information, with a simulation view through colour-perception and monochrome transformations

  • color-independent fixtures

media

captions, transcripts, audio description and sound-only signalling — including cases whose honest outcome is cannot-tell, not pass

  • media fixtures

ui-states

one journey across loading, empty, invalid, corrected, submitted, error, offline, permission-denied, timed-out and busy

  • ui-states fixtures

journeys

multi-page tasks — carrying the criteria that cannot be tested on a single page at all: consistent navigation, identification, help, redundant entry

  • journeys fixtures

scenarios

remaining scenario types at their honest unit — overlays, async, paging, theming, orientation, RTL, touch targets, voice control, dragging

  • scenarios fixtures

surfaces

beyond a plain web page — HTML email, EPUB metadata, an authoring tool and its output (ATAG 2.0), and a conversational interface

  • surfaces fixtures

guided

questions automation cannot answer, with the fixture to ask them against and a slot for evidence — every one expects cannot-tell

  • guided fixtures

aaa

the WCAG AAA criteria that are decidable from markup or by driving the page, as matched broken/corrected pairs — not a conformance claim about any site

  • aaa fixtures

wiring

ONE constant defect — a div acting as a button — with the click handler attached four ways, because a corpus that only writes onclick is easier than the web

  • wiring fixtures

flash

flash and seizure thresholds — SEIZURE WARNING: these can produce flashing light. Nothing flashes on load; each needs a button press and stops after 3s

  • flash fixtures
