Release notes

Every paragraph here is set in a block narrower than eighty characters, aligned to the start edge only, with line spacing of 1.6 and paragraph spacing 1.5 times that.

Ragged-edge setting keeps word spacing even, so no rivers of white space open down the block, and the looser leading makes it easier to find the start of the next line. Both help readers who track lines slowly.
